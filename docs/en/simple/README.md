       Tell the system about your house and your power prices

   3️⃣  Teach an appliance  →  03-teach-an-appliance.md
       ⭐ The important one — switch one on so the
          system learns it

   4️⃣  Dashboard  →  04-dashboard.md
       See what the house is using right now

   5️⃣  Where the money goes  →  05-where-the-money-goes.md

   6️⃣  Answer questions  →  06-answer-questions.md

💡  WHAT THE APP DOES, IN ONE LINE

   Your house has ONE electricity meter.
   WattWiser watches its single total number
   and works backwards to tell you which
   appliance is using what.
