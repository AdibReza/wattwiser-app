# WattWiser User Guide

Written for a **normal user**. No commands to type, no technical terms. One page
per screen: what it does, when to use it, what to click.

---

## The six screens you'll use

| #   | Screen                                           | What it's for                                                              |
|-----|--------------------------------------------------|----------------------------------------------------------------------------|
| 1   | [Set up your home](./uc-01-household-setup.md)   | Tell the system about your home and how you pay for power                  |
| 2   | [Appliance list](./uc-02-appliance-inventory.md) | List every electrical appliance in the house                               |
| 3   | [Teach it an appliance](./uc-03-calibration.md)  | **The important one** — switch one appliance on so the system can learn it |
| 4   | [Dashboard](./uc-04-dashboard.md)                | See what the house is drawing right now                                    |
| 5   | [Where the money goes](./uc-05-breakdown.md)     | See what each appliance cost you this month                                |
| 6   | [Answer questions](./uc-06-confirmations.md)     | Confirm a run when the system isn't sure                                   |

## Two pages that aren't for users

| #   | Page                                           | For                                                     |
|-----|------------------------------------------------|---------------------------------------------------------|
